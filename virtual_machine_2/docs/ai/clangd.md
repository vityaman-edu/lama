# clangd

Use the project compilation database generated by `make compile_commands`.
Keep `--compile-commands-dir=${workspaceFolder}` in the VS Code settings and
add `--query-driver=` with an empty value.

The installed Nix clangd wrapper injects Nix standard-library include paths
unless a `--query-driver` argument is present. On macOS this mixes Nix headers
with the Apple SDK selected by the compilation database. The empty value
prevents that injection without querying a compiler or adding extra include
paths. clangd then discovers the Apple headers from the existing compile flags.

Validate each project source and header with
`clangd --query-driver= --check=<file> --log=error`. Standard-library errors
must disappear. Existing source errors and Clang Tidy findings remain enabled.
Restart the editor's clangd server after changing its arguments.
